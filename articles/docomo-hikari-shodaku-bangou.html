ドコモ光の事業者変更承諾番号の取り方【2026年9月】発行窓口・15日の期限・取る前の7チェック

更新日:2026年9月25日 公開日:2026年9月25日 執筆:もりそん

ⓘ 本記事にはアフィリエイト広告(プロモーション)が含まれます。評価・解説は編集ポリシーに基づいています。

ドコモ光から他社の光コラボへ乗り換えるとき、最初にやることが事業者変更承諾番号の発行です。ドコモ公式の案内では、申し込み方法は「Web・ドコモショップ/d garden・お電話」の3つ、電話の受付時間は午前9時〜午後8時、番号の有効期限は発行日を含めて15日間と明記されています(2026年9月時点)。

ここでつまずく人が多いのは、番号そのものの取り方ではありません。15日という短い期限の中に、乗り換え先の選定・工事費残債の精算・オプションの引き継ぎ判断を全部押し込んでしまうことです。この記事は「取る手順」だけでなく、取る前に何を確定させておくかを逆算で整理します。

先に結論

承諾番号は乗り換え先を決めてから最後に取るのが正解です。Webなら24時間、電話(ドコモケータイから151/一般電話から0120-800-000)は午前9時〜午後8時で申し込めます。期限は発行日を含め15日。事務手数料は3,300円(税込)で、契約期間内の解約ならドコモ光1ギガで戸建5,500円・マンション4,180円の解約金も乗ります。なおauひかり・NURO光へ移るなら承諾番号は不要(新規契約+解約の扱い)です。

そもそも承諾番号が要る乗り換え・要らない乗り換え

最初にここを間違えると、取る必要のない番号を取って15日を溶かすことになります。事業者変更はNTT東日本・西日本のフレッツ光の設備を共用する事業者どうしの乗り換えの仕組みです。ドコモ光もその「光コラボレーション(光コラボ)」の1つなので、同じ光コラボへ移る場合だけ承諾番号を使います。

乗り換え先回線の種類承諾番号手続きの名前
GMOとくとくBB光・ソフトバンク光・ビッグローブ光・ahamo光など 光コラボ(フレッツ網) 必要 事業者変更
フレッツ光(NTT東西と直接契約) フレッツ光 必要 事業者変更
auひかり 独自回線(KDDI) 不要 新規契約+ドコモ光の解約
NURO光 独自回線(ソニーネットワークコミュニケーションズ) 不要 新規契約+ドコモ光の解約
電力系(eo光・コミュファ光など) 独自回線 不要 新規契約+ドコモ光の解約

ここで実務的に効いてくる差は3つあります。ひとつは工事の有無。事業者変更なら宅内の配線もONUもそのまま使えるので、原則として工事の立ち会いがありません。ふたつめは不通期間。事業者変更は切替日に自動で移行するため、ネットが使えない空白日がほぼ発生しません。みっつめは特典の厚みで、独自回線への新規契約のほうがキャッシュバックは手厚い傾向があります。

✅ 3行で自己判定
  • 移りたい先が光コラボ → 承諾番号を取る(この記事の手順)
  • 移りたい先がauひかり・NURO光・電力系 → 番号は取らない。乗り換えの5ステップに沿って「開通確認後に解約」の順で進める
  • まだ決まっていない → 先に決める。番号の発行はいちばん最後でいい

なお、NURO光には既設の光ファイバーを活かす「光回線再利用」という申し込み方法がありますが、これは工事を軽くするための仕組みであって、手続き上は事業者変更ではなく新規契約です。承諾番号は使いません。

発行窓口は3つ。受付時間と向き不向き

ドコモ公式では、事業者変更承諾番号の申し込み方法として「Web」「ドコモショップ/d garden」「お電話」の3つが案内されています。それぞれの受付時間と、どんな人に向くかを整理します。

窓口受付時間向いている人注意点
Web(ドコモのオンライン手続き) 24時間(メンテナンス時を除く) dアカウントでログインでき、自分で条件を確認しながら進めたい人 ahamo光は原則Webのみ。ネットワーク暗証番号が必要
電話(151 / 0120-800-000) 午前9時〜午後8時 契約内容や残債を口頭で確認しながら進めたい人 混雑時は待ち時間が出る。引き止めの案内を受けることがある
ドコモショップ / d garden 各店舗の営業時間内 対面で確認したい人、書類の読み合わせをしたい人 本人確認書類が必要。来店予約をしておくと待ち時間が短い

電話番号は、ドコモのケータイからなら151(無料)、一般電話からなら0120-800-000です。受付は午前9時〜午後8時。ahamo光を契約している場合は「原則Webのみ」とドコモ公式に記載があるため、電話窓口を前提に予定を組まないよう注意してください。

⚠ 「即日発行」を前提にしない

Webの受付が24時間だからといって、番号が即座に手元に届くとは限りません。発行の連絡が届くまでの時間はドコモ側の処理状況に左右されます。切替希望日が決まっているなら、希望日の3〜4週間前を目安に動き始めるほうが安全です。

番号を取る前に確定させる7項目

ここがこの記事の本題です。承諾番号は取った瞬間に15日のタイマーが走り出します。そのタイマーが走っている間に調べ物をしないで済むように、先に潰しておくべき項目を7つに絞りました。全部で30〜40分程度で確認できます。

  1. 1. 乗り換え先を1社に決めきる

    「A社とB社で迷っている」状態で番号を取るのがいちばん危険です。特典の比較は番号の前に終わらせてください。スマホのセット割を起点に選ぶなら光回線おすすめ7社比較、キャッシュバックの受け取り時期で選ぶならキャンペーン比較が判断材料になります。

  2. 2. 工事費の残債額を確認する

    ドコモ光の工事料を分割で支払っている途中の場合、ドコモ公式には承諾番号の取得時に残りを一括精算する旨の記載があります。「実質無料」で契約していても、割引が途中で止まる分は自己負担です。マイドコモの請求内訳で残り回数を確認しておきましょう。

  3. 3. 契約期間(定期契約)の残りを確認する

    定期契約の期間内なら解約金がかかります。更新月まで2〜3ヶ月なら、待ったほうが得なこともあれば、乗り換え先の特典のほうが大きいこともあります。金額は次章の早見表で比べてください。

  4. 4. ドコモ光セット割の代わりを決める

    ドコモ光を解約すると、ドコモのスマホに付いていたドコモ光セット割は廃止または割引額が変更になります(ドコモ公式の注意事項)。家族回線にまとめて効いていた場合、影響額は月あたり数千円になることもあります。スマホもまとめて見直す前提なら、スマホ料金の見直しと合わせて計算してください。

  5. 5. ドコモ光電話の番号をどうするか決める

    電話番号を引き継げるかは「その番号がもともとNTTのアナログ回線由来かどうか」で変わります。乗り換え先が光電話を提供していない場合はNTTとの直接契約になり手数料がかかる、という注意もドコモ公式に書かれています。そもそも固定電話が必要かどうかはひかり電話は必要かで棚卸しできます。

  6. 6. プロバイダのメールアドレスの行き先を決める

    ドコモ光ではプロバイダを選択して契約しているため、そのプロバイダのメールアドレスは使えなくなる可能性があります。ネット銀行・各種サービスの登録メールに使っているなら、乗り換え前にGmailなどへ付け替えておくのが安全です。

  7. 7. ペア回線のスマホを先に動かさない

    ドコモ公式には、ペア回線に設定している携帯電話は事業者変更が完了するまで解約・MNPの手続きができない旨の記載があります。スマホのMNPも予定しているなら、光の切替完了を待ってからにしてください。

  • 工事費の残債額を確認した
  • 更新月と解約金の額を確認した

  • プロバイダメールの付け替えを済ませた
  • スマホのMNPは光の切替後に回した

15日をどう使うか(カウントダウン表)

有効期限は「発行日を含めて15日間」です。ここを「発行日の翌日から15日」と数えると1日ずれます。9月25日に発行されたなら、9月25日が1日目、10月9日が15日目という数え方です。

日数やること間に合わないと何が起きるか
1日目(発行日) 番号を受け取り、その日のうちに乗り換え先へ申し込む ここで止まるのが最多の失敗パターン
2〜3日目 乗り換え先から届く申込内容の確認メールをチェック。番号の入力ミスがないか照合 桁の打ち間違いで審査が止まる
4〜7日目 乗り換え先から切替日の連絡が来る。都合が悪ければこの時点で調整 連絡を見落とすと自動で日程が決まる
8〜14日目 予備日。連絡が来ない場合は乗り換え先へ問い合わせる ここを空けておかないと再発行になる
15日目 期限最終日。ここまでに乗り換え先の受付が完了していること 無効になり、ドコモへ再発行を依頼し直し

ポイントは「1日目に申し込む」の一点です。番号を取ってから乗り換え先のキャンペーン内容を読み比べ始めると、審査や在庫確認で数日取られたときに一気に苦しくなります。逆に1日目に申し込んでしまえば、8日目以降を丸ごと予備日に使えます。

知人から「番号を取ったけど、どこに申し込むか決まっていない」という相談を受けたことがあります。結局そのときは期限内に決めきれず再発行になりました。番号は"最後の一手"で、最初の一手ではありません。
運営者・もりそん

期限が切れても、ドコモ光の契約自体が解約されるわけではないので回線は止まりません。再発行を依頼すればやり直せます。ただし手間が増えるうえ、乗り換え先のキャンペーンが月替わりで変わる場合は条件が変わってしまうこともあります。

かかる費用の場合分け早見表

ドコモ光から出るときにかかるお金は、大きく①事業者変更事務手数料 ②解約金(契約期間内の場合) ③工事費の残債の3つです。2026年9月時点のドコモ公式表記をもとに整理します。

費目金額発生条件
事業者変更事務手数料 3,300円(税込) 原則発生。ただし公式に「請求対象外」となる条件の記載があるため、自分の契約が該当するかは要確認
解約金|ドコモ光1ギガ 戸建 5,500円(税込) 定期契約の期間内に解約した場合
解約金|ドコモ光1ギガ マンション 4,180円(税込) 同上
解約金|ドコモ光10ギガ 戸建 5,500円(税込) 同上
解約金|ahamo光1ギガ 戸建 / マンション 4,950円 / 3,630円(税込) 同上
工事費の残債 残り回数×分割額 分割払いの途中で乗り換える場合。承諾番号の取得時に一括精算

なお、2022年6月30日以前に申し込んだ古い契約は戸建14,300円・マンション8,800円という旧水準の解約金が残っている場合があります。「解約金は月額1ヶ月分くらい」という最近の相場感は2022年7月の制度改正以降の契約の話なので、長く使っている人ほど自分の契約書を確認してください。

⚠ 「更新月まで待つ」が得とは限らない

解約金が4,180円〜5,500円なら、乗り換え先のキャッシュバックで相殺できることがほとんどです。待つ判断が効くのは、工事費の残債が1万円を大きく超えているケース。残債は待っても消えるのではなく毎月の割引で相殺されていく設計なので、「あと何ヶ月で割引が終わるか」で判断してください。2年ごと乗り換えの損益分岐で5年総額を試算しています。

ドコモ光電話・テレビ・ペア回線の落とし穴

手続きそのものより、ここで揉めるほうが多い、というのが正直なところです。ドコモ公式の注意事項にも明記されている3点を、順に噛み砕きます。

1. オプションは自動では移らない

ドコモ光電話・ドコモ光テレビオプションといったオプションは、乗り換え先が同等のサービスを提供していない場合、NTTとの直接契約に切り替わり手数料がかかるとドコモ公式に記載があります。「ネットだけ移せばいい」と考えていると、テレビが映らなくなって初めて気づく、というのがありがちな流れです。乗り換え先の申し込み画面で、光電話・光テレビのオプションを同時に申し込んでおいてください。

2. ドコモ光セット割は消える

ドコモのスマホとドコモ光をセットで契約していた場合、光を解約するとセット割は廃止または割引額が変更になります。家族3〜4回線に効いていたなら、月あたりの影響はそれなりです。「光の月額がいくら下がるか」ではなく「世帯の通信費が合計でどうなるか」で比べてください。ドコモのスマホを続けるつもりなら、光そのものを変えずにプロバイダだけ見直す選択肢もあります。

3. ペア回線のスマホは切替完了まで動かせない

ペア回線に設定している携帯電話は、事業者変更が完了するまで解約・MNPの手続きができないとされています。「光もスマホもまとめて格安に移す」という計画を立てている人は、光 → スマホの順で動かすのが確実です。逆順にすると、スマホのMNPが先に通ってペア回線の紐付けが崩れ、光側の手続きが止まることがあります。

ちなみに切替後のネット環境ですが、事業者変更ではONU(回線終端装置)はそのままで、プロバイダ側の機器だけが変わるのが一般的です。ルーターは乗り換え先のIPv6方式(v6プラス・transixなど)に対応しているか確認しておくと、切替日に「つながらない」と慌てずに済みます。仕組みはIPv6 IPoEの解説に、機器の選び方は光回線のルーターの選び方にまとめています。

🧭 承諾番号を取る前に、乗り換え先を決めきる

光コラボ同士なら工事なし・不通期間ほぼゼロで移れます。契約期間の縛りと解約違約金がないタイプを選んでおくと、次に条件が変わったときも身軽に動けます。プロバイダ一体型でIPv6 IPoE標準対応、対応ルーターのレンタルもあります。

発行後によくあるつまずき4つ

つまずき1:番号の桁を打ち間違える

事業者変更承諾番号は11桁です。手で書き写すと「0」と「O」、「1」と「I」を取り違えます。SMSやメールで届いた文字列をコピー&ペーストで入力してください。桁が合っていても1文字違えば審査が通りません。

つまずき2:契約者名義が一致していない

ドコモ光の契約名義と、乗り換え先に申し込む名義が違うと手続きできません。旧姓のまま・親名義のまま、というケースは意外と多いので、名義変更が必要なら承諾番号を取る前に済ませるのが鉄則です。名義変更には日数がかかるため、15日のタイマーの中に入れてはいけません。

つまずき3:「解約してから申し込む」をやってしまう

ドコモ光を先に解約すると、回線設備の権利がNTTに戻り、事業者変更の前提そのものが崩れます。そうなると乗り換え先は新規扱いになり、工事が必要になったり、不通期間が発生したりします。承諾番号を取った後にドコモへ解約の連絡を入れる必要はありません。ドコモ公式の説明でも、事業者変更の完了日は乗り換え先が決定し、その完了をもってドコモ光が解約になる扱いです。

つまずき4:切替日の前後にレンタル機器を返してしまう

プロバイダから借りていたルーターなどは、返却の案内が来てから返します。切替日より前に返すと、当日ネットにつなげません。逆に返却を忘れると機器代金を請求されることがあるので、返却キットが届いたらその週のうちに送るくらいの温度感がちょうどいいです。解約側の手順全般は光回線の解約手順と違約金にまとめています。

Webの手続きは24時間受け付けており、電話窓口は午前9時〜午後8時です。ただし発行の連絡が届くまでの時間はドコモ側の処理状況によるため、当日中に必ず届くと約束されているわけではありません。切替希望日から逆算して、余裕をもって申し込むのが安全です。
承諾番号の有効期限が切れたらどうなりますか?
有効期限は発行日を含めて15日間です。期限内に乗り換え先での手続きが完了しなかった場合は番号が無効になり、あらためて発行を依頼し直すことになります。ドコモ光の契約自体が解約されるわけではないので、回線が止まることはありません。
auひかりやNURO光へ移るときも承諾番号は必要ですか?
必要ありません。事業者変更はNTT東日本・西日本のフレッツ光設備を使う光コラボ同士の乗り換えの仕組みです。auひかりやNURO光は独自設備を使うため、手続きは「新規契約+ドコモ光の解約」になり、承諾番号は使いません。乗り換えの5ステップの順番で進めてください。
承諾番号を取ったら、ドコモ光は自動で解約になりますか?
番号を取っただけでは解約になりません。ドコモの公式説明では、事業者変更の完了日は乗り換え先の事業者が決定し、その完了をもってドコモ光・ahamo光が解約となる扱いです。したがって自分でドコモへ解約の電話を入れる必要はありません。
ドコモ光電話の番号はそのまま使えますか?
元がNTTのアナログ回線から引き継いだ番号であれば継続できるケースが多い一方、ドコモ光で新たに発番した番号は引き継げないのが一般的です。乗り換え先が同等のオプションを提供していない場合はNTTとの直接契約に切り替わり手数料がかかる、という注意書きもドコモ公式に記載があります。申し込み前に両社へ確認してください。
ペア回線のスマホがあると何か制約がありますか?
ドコモ公式には、ペア回線に設定している携帯電話は事業者変更が完了するまで解約やMNPの手続きができない旨の記載があります。スマホの乗り換えも同時期に考えている場合は、先に光の切替を終えてからスマホを動かす順番が無難です。

まとめ:番号は"最後の一手"

  • 承諾番号が要るのは光コラボ同士の乗り換えだけ。auひかり・NURO光は新規契約扱いで番号は不要
  • 窓口はWeb(24時間)・電話(午前9時〜午後8時)・ドコモショップの3つ。ahamo光は原則Webのみ
  • 期限は発行日を含めて15日。1日目に乗り換え先へ申し込めば、後半を丸ごと予備日にできる
  • 費用は事務手数料3,300円+契約期間内なら解約金+工事費残債。判断を左右するのは残債
  • 取る前に乗り換え先・残債・更新月・セット割・光電話・メール・ペア回線の7項目を確定させる

乗り換え先がまだ固まっていないなら、先に7社比較で候補を2つまで絞ってから戻ってきてください。番号を取るのは、そのあとで十分です。
